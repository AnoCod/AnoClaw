# AnoClaw 3.0 用户指南

AnoClaw 是一家公司形态的本地 AI 桌面应用。你只需要和 MainAgent 说明目标；它会持续建立 Team、培养 Agent、拆分工作、并行执行和汇总结果。

## 第一次使用

1. 输入本地公司名称。
2. 创建一项 Work。
3. 选择一次性工作，或为长期项目选择本地 Workspace 文件夹。
4. 在主界面向 MainAgent 描述目标和验收标准。

不需要账号。公司、工作、会话和记忆保存在本机。

## Work 与 Workspace

Work 统一承载“一次性任务”和“项目”：

- 一次性 Work：适合问答、研究、规划和临时交付，不绑定文件夹。
- 项目 Work：绑定 Workspace，适合持续开发、文档、数据、内容或运营项目。
- Workspace 可以被多项 Work 复用，因此一次讨论可以逐渐成长为长期项目。

## 公司如何工作

MainAgent 会在需要时：

- 创建持久 Team；
- 创建或邀请持久 Agent；
- 建立 Mission 与验收标准；
- 把工作拆成有依赖的 Task；
- 让多个员工并行执行；
- 请求独立 Agent 或你本人验收；
- 在失败、停止或重启后恢复可安全继续的工作。

用户不需要理解这些对象才能使用产品。

## 透明会话

专业布局下可展开“员工会话树”，查看每次委派的任务上下文、员工回复和工具结果。员工会话只读；即使正在查看员工会话，输入仍会发送给 MainAgent。

## 中英文

在“设置”中选择简体中文或 English。界面立即切换并记住偏好；用户输入和 Agent 已产生的内容不会被改写。

## 停止与验收

- “暂停工作”会阻止新任务并停止当前非终止 Task，释放 Workspace 租约；之后可继续。
- Task 采用用户验收时，执行摘要会出现“通过验收/要求修改”。
- 服务端、独立员工或用户验收未通过时，Task 会进入修改流程，而不是伪装成完成。
